# Investing Demo — Functional Requirements

**Trigger:** Use this skill when implementing, modifying, or testing any feature of the Investing Demo — share listing, details, CRUD, authentication, price updates, REST API, or admin panel.

## Назначение приложения

Веб-приложение для мониторинга рыночных цен акций через API брокера «Тинькофф Инвестиции». Пользователи могут просматривать список акций, их текущие цены, тренды и исторические графики. Авторизованные пользователи могут управлять каталогом акций (CRUD). Приложение предоставляет REST API для программного доступа к данным.

## Функциональные требования

### FR-1: Просмотр списка акций
Любой пользователь (включая неавторизованного) может просматривать пагинированный список акций с тикером, названием, ISIN и текущей ценой. Цена с цветовой индикацией: зелёный — рост, красный — падение. Список отсортирован по алфавиту (поле `name`), размер страницы — 100 записей.
**Реализация:** `ShareListView` (`dashboard/views.py:20-26`), шаблон `list.html`.

### FR-2: Детальная информация об акции
Страница акции с текущей ценой, временем обновления и графиком исторических цен за 180 дней (дневные свечи, Plotly).
**Реализация:** `ShareDetailView` (`dashboard/views.py:29-38`), `services/graph.py`, шаблон `detail.html`.

### FR-3: Регистрация пользователя
Гость регистрируется, указав email и пароль с подтверждением. Проверка уникальности email и совпадения паролей. Автоматическая авторизация после регистрации.
**Реализация:** `RegistrationView` (`user/views.py:36-55`), `RegistrationForm` (`user/forms.py:8-51`), шаблон `registration.html`.

### FR-4: Авторизация пользователя
Вход по email и паролю. Сообщение об ошибке при неудачной попытке.
**Реализация:** `AuthView` (`user/views.py:8-33`), `AuthForm` (`user/forms.py:54-68`), шаблон `auth.html`.

### FR-5: Выход из системы
Авторизованный пользователь может выйти.
**Реализация:** `LogoutView` (`user/views.py:58-64`).

### FR-6: CRUD акций (только авторизованные)
Авторизованный пользователь может добавлять, редактировать и удалять акции. Кнопки видны только авторизованным. Неавторизованные пользователи перенаправляются на главную страницу.
**Реализация:** `IsUserAuthenticatedMixin` (`dashboard/views.py:11-17`), `ShareCreateView` (`views.py:41-46`), `ShareUpdateView` (`views.py:49-55`), `ShareDeleteView` (`views.py:58-63`).

### FR-7: Периодическое обновление цен
Celery Beat запускает `update_last_price` каждые 10 секунд. Обновляет `last_price` и `is_trend_high` через Tinkoff API.
**Реализация:** `config/celery.py` (beat_schedule), `dashboard/tasks.py`.

### FR-8: REST API для акций
`/api/v1/shares/` с CRUD, пагинацией (LimitOffset, 100 записей), фильтрацией по `name` и `ticker`, сортировкой, поиском по `name`.
**Реализация:** `dashboard/api/v1/views.py`, `serializer.py`, `router.py`.

### FR-9: Загрузка каталога акций
Management-команда `add_shares` загружает список акций из Tinkoff API.
**Реализация:** `dashboard/management/commands/add_shares.py`.

### FR-10: Django Admin
Администратор может просматривать, искать и редактировать акции. Поиск по `figi`, `isin`, `name`, `ticker`.
**Реализация:** `dashboard/admin.py`.

## Бизнес-правила

### BP-1: Уникальность идентификаторов акции
Поля `figi`, `ticker`, `uid` должны быть уникальными в таблице `Share`.

### BP-2: Ограничение доступа к CRUD-операциям
Добавление, редактирование и удаление акций доступно только авторизованным пользователям.

### BP-3: Визуальная индикация тренда цены
Зелёный фон (`mediumseagreen`) — цена выросла. Красный фон (`palevioletred`) — цена упала или тренд не определён.

### BP-4: Пагинация списка акций
100 записей на страницу с навигацией.

### BP-5: Сортировка списка акций
По алфавиту по полю `name`.

### BP-6: Проверка при регистрации
Пароли должны совпадать, email должен быть уникальным.

### BP-7: Автоматическая авторизация после регистрации
После успешной регистрации пользователь автоматически входит в систему.

### BP-8: Период графика исторических цен
180 дней с дневным интервалом свечей.

### BP-9: Логика определения тренда
Если текущая цена выше предыдущей — `is_trend_high = True` (рост). Если ниже — `False` (падение).

### BP-10: REST API — пагинация и фильтрация
LimitOffset-пагинация (100 записей), фильтрация по `name`/`ticker`, сортировка, поиск по `name`.

## Неоднозначности реализации

### A-1: Модель User без кастомизации
`username` устанавливается равным email. Пользователь вводит только email, но система хранит его и как `username`, и как `email`.

### A-2: Отсутствие связи пользователь → акции
Нет понятия «мой портфель» или «мои наблюдения». Все акции доступны всем пользователям одинаково.

### A-3: График использует линейный график, а не свечи
Данные запрашиваются как дневные свечи, но строится линейный график (`Scatter` с `mode="lines"`), используя только `close` цены.

### A-4: Дублирование кода подключения к Tinkoff API
`Client(TINKOFF_TOKEN)` создаётся отдельно в `market_data.py`, `graph.py` и `add_shares.py` — нет единой точки подключения.
